# Natesclaw NovitaAI provider

Official Natesclaw provider plugin for NovitaAI's OpenAI-compatible API.

## Install

```sh
natesclaw plugins install @natesclaw/novita-provider
natesclaw gateway restart
```

## Docs

See `docs/providers/novita.md` in the Natesclaw repository, or the published
docs at `https://docs.natesclaw.ai/providers/novita`.
