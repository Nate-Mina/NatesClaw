# BytePlus plugin

Adds BytePlus, BytePlus Plan model provider support to Natesclaw.

## Distribution

- Package: `@natesclaw/byteplus-provider`
- Install route: npm; ClawHub: `clawhub:@natesclaw/byteplus-provider`

## Surface

providers: `byteplus`, `byteplus-plan`; contracts: `videoGenerationProviders`
