# Volcengine plugin

Adds Volcengine, Volcengine Plan model provider support to Natesclaw.

## Distribution

- Package: `@natesclaw/volcengine-provider`
- Install route: npm; ClawHub: `clawhub:@natesclaw/volcengine-provider`

## Surface

providers: `volcengine`, `volcengine-plan`; contracts: `speechProviders`
