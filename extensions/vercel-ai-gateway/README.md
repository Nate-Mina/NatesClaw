# Vercel AI Gateway Natesclaw provider

Official Natesclaw provider plugin for Vercel AI Gateway.

## Install

```sh
natesclaw plugins install @natesclaw/vercel-ai-gateway-provider
```

## Docs

See `docs/providers/vercel-ai-gateway.md` in the Natesclaw repository, or the published docs at `https://docs.natesclaw.ai/providers/vercel-ai-gateway`.
